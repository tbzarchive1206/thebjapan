# Dodawanie nowych materiałów THE B JAPAN

1. Dodaj zdjęcie, film lub dokument do odpowiedniego folderu na Google Drive.
2. Zachowaj publiczny dostęp `Każdy, kto ma link → Wyświetlający` dla folderu źródłowego.
3. Poczekaj na automatyczną synchronizację wykonywaną co 12 godzin albo uruchom ją ręcznie przez `Actions → Update THE B JAPAN archive → Run workflow`.
4. Po statusie `Success` odśwież stronę GitHub Pages.

Nowy folder utworzony bezpośrednio w folderze głównym stanie się podstroną. Folder utworzony poziom niżej stanie się galerią. Kolejne podfoldery będą sekcjami wewnątrz galerii.
